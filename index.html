Alternativa k TradingView, která běží u vás

TickView je zcela zdarma – open-source desktopová a webová aplikace pro svíčkové grafy akcií, ETF, forexu, futures a kryptoměn, kterou můžete používat místo TradingView přímo na svém počítači. Data bere z bezplatných zdrojů, všechno ukládá lokálně a nikdy nic neobchoduje – je pouze pro čtení.

Všechno, co od grafu čekáte

Ovládání vychází z toho, na co jsou obchodníci zvyklí z webových platforem. Jen to běží na vašem počítači.

Grafy a timeframy

Svíčky, bary, Heikin Ashi, čára, plocha, baseline a další. Timeframy 1m až 1W, živé doplňování a automatické donačítání starší historie při posunu doleva.

Kreslení

Trendové čáry, kanály, Fibonacci, pitchfork, obdélníky, text, Long/Short position s výpočtem rizika a měřič. Kresby se ukládají k symbolu a jsou vidět na všech timeframech.

Indikátory

SMA, EMA, VWAP, Bollinger, Ichimoku, Supertrend, RSI, MACD, Stochastic, ATR, OBV a další. Nastavitelné parametry, šablony, oblíbené a panely, které jde tažením zvětšovat i přeskládat.

Více grafů najednou

Rozložení až 16 grafů, každý s vlastním symbolem, timeframem a indikátory. Synchronizace symbolu, intervalu, crosshairu i časového rozsahu.

Watchlisty

Libovolný počet seznamů symbolů s poslední cenou a denní změnou. Klik přepne graf, symboly lze řadit a stejný symbol může být ve více seznamech.

Alerty a notifikace

Alert na cenu, na kreslenou čáru nebo na signál indikátoru. Vyhodnocuje je server na pozadí i bez otevřené stránky a posílá Telegram, webhook, toast nebo zvuk.

Scanner

Indikátor se signály projde až 40 symbolů napříč zdroji na zvoleném timeframu a výsledek ukáže v tabulce v grafu. Volitelně upozorní ještě před zavřením svíčky.

Replay a backtest

Přehrajte historii svíčku po svíčce a obchodujte ručně na simulovaném účtu se spreadem, skluzem a komisí. Libovolný počet sessions, každá s vlastními obchody a kresbami.

COT report CFTC

Pozice hedgerů, velkých spekulantů a drobných obchodníků a COT Index s daty zdarma z API CFTC. Trh se odvodí ze symbolu – futures, forex, kovy, indexy i krypto.

Jak TickView vypadá

Skutečné snímky aplikace v tmavém motivu – žádné makety. Kliknutím otevřete obrázek v plné velikosti.

TickView vs. TradingView

TradingView je rozsáhlá cloudová platforma s obrovskou komunitou. TickView jde jinou cestou: bezplatná open-source aplikace, která běží jen na vašem počítači. Srovnání níže ukazuje i to, co TickView neumí – vyberte si podle toho, co potřebujete.

Bez API klíče

Historie se ukládá do lokální cache v SQLite a ze sítě se stahuje jen chybějící úsek. Každý zdroj má vlastní omezovač dotazů a při chybě 429 čeká s exponenciálním odstupem.

Vlastní indikátory v Pythonu

Indikátor je jedna třída v samostatném adresáři. Dostane svíčky jako pandas DataFrame, parametry a kontext instrumentu a vrátí čáry, úrovně, úsečky, značky, tabulky, barvu pozadí nebo signály.

  • Formulář parametrů s kontrolou hodnot se vytvoří sám ze schématu.
  • Signály z indikátoru fungují v alertech i ve scanneru.
  • Indikátor si může vyžádat externí data, například COT report.
  • Testy indikátoru leží vedle něj a python -m unittest je najde.
tickview/indicators/custom/ema_cross/indicator.py 
from tickview.indicators.api import Indicator, Line, Param, Result


class EmaCross(Indicator):
    id = "ema_cross"
    title = "EMA×"
    name = "Křížení dvou EMA"
    params = [
        Param.int("fast", 9, "Rychlá"),
        Param.int("slow", 21, "Pomalá"),
    ]

    def compute(self, df, params, ctx):
        close = df["close"]
        fast = close.ewm(span=params["fast"]).mean()
        slow = close.ewm(span=params["slow"]).mean()
        return Result(lines=[
            Line("Rychlá", fast),
            Line("Pomalá", slow),
        ])


INDICATOR = EmaCross()

Instalace a spuštění

Stačí Python 3.12 nebo 3.13 – skript si sám vybere správnou verzi a na Windows ji v případě potřeby i nainstaluje. Aplikace se otevře v prohlížeči na http://localhost:8095, volitelně i v nativním okně.

curl -L https://github.com/svopex/TickView/archive/refs/heads/main.tar.gz | tar xz
cd TickView-main
./run.sh --open

Stáhne aktuální verzi do složky TickView-main – stačí curl a tar, které macOS i Linux mají. Skript run.sh vytvoří .venv, doinstaluje závislosti a spustí aplikaci. 

curl.exe -L -o TickView.zip https://github.com/svopex/TickView/archive/refs/heads/main.zip
tar -xf TickView.zip
cd TickView-main
.\run-windows.bat --open

Funguje v příkazové řádce i v PowerShellu na Windows 10 a 11, curl a tar jsou součástí systému. Skript najde Python (když chybí, sám ho nainstaluje jen pro vás, bez administrátorských práv), připraví .venv, doinstaluje závislosti a otevře prohlížeč.

Časté otázky

Krátké odpovědi na to, na co se lidé ptají nejčastěji – hlavně ve srovnání s TradingView.

Je TickView opravdu zdarma?

Ano. TickView je open source pod licencí Apache 2.0 a nemá předplatné, registraci ani reklamy. Data z Binance, Yahoo Finance a CFTC jsou zdarma bez API klíče, Alpaca nabízí bezplatný klíč (plán Basic). Pro Interactive Brokers potřebujete účet u IB (stačí demo) a rozsah dat závisí na vašem předplatném.

Dá se TickView použít místo TradingView?

Pro technickou analýzu na vlastním počítači ano: svíčkové grafy, 28 vestavěných indikátorů, kreslení, watchlisty, alerty, scanner, replay a až 16 grafů najednou. TradingView ale nenahradí, pokud potřebujete Pine Script, mobilní aplikaci, synchronizaci v cloudu, sociální síť s nápady nebo obchodování přes brokera přímo z grafu.

Podporuje TickView Pine Script?

Ne. Vlastní indikátory se v TickView píší v Pythonu: jedna třída dostane svíčky jako pandas DataFrame a vrátí čáry, značky, tabulky nebo signály. Skripty v Pine Script je potřeba do Pythonu přepsat.

Odkud TickView bere data?

Z Binance (kryptoměny, živě), Yahoo Finance (akcie, ETF, indexy, forex a futures, zpožděně), Alpaca (americké akcie, živě po zadání klíče), Interactive Brokers přes TWS nebo IB Gateway a z veřejného API CFTC pro COT report. Historie se ukládá do lokální cache v SQLite.

Na jakých systémech TickView běží?

Na Windows, macOS i Linuxu s Pythonem 3.12 nebo 3.13. Spouštěcí skript si připraví prostředí sám, na Windows Python v případě potřeby i nainstaluje. Aplikace se otevře v prohlížeči na localhost, volitelně v nativním okně.

Kde jsou uložená moje data a API klíče?

Jen na vašem počítači. Cache svíček, nastavení, kresby a watchlisty jsou v lokální databázi SQLite, API klíče v souboru config.yaml. TickView nemá žádný účet ani vlastní server; připojuje se jen ke zvoleným zdrojům dat a k Telegramu nebo webhooku, pokud si je nastavíte pro alerty.

Umí TickView zobrazit COT report?

Ano. Indikátory COT ukazují pozice hedgerů, velkých spekulantů a drobných obchodníků i COT Index s daty zdarma z API CFTC. Trh se odvodí ze symbolu – futures, forex, kovy, indexy i kryptoměny.

Je TickView spojený se společností TradingView?

Ne. TickView je nezávislý open-source projekt a není spojen se společností TradingView, Inc. Grafy vykresluje open-source knihovna Lightweight Charts™ od TradingView pod licencí Apache 2.0. TradingView je ochranná známka společnosti TradingView, Inc.
